📚 Теорія, вижимка та терміни — Лекція 1 (OSI, TCP/IP, Ethernet, MAC)
Ключові принципи:
  • Інкапсуляція (L7→L1): кожен рівень додає свій заголовок (L2 ще й трейлер FCS/CRC).
  • TCP 3-Way Handshake: SYN → SYN-ACK → ACK (надійне з'єднання), на відміну від UDP.
  • Комутатор L2: вчить Source MAC, пересилає по Destination MAC.
3 дії комутатора:
  • Flooding: Broadcast (FF:FF:FF:FF:FF:FF) або Unknown Unicast → на всі порти крім вхідного.
  • Forwarding: Destination MAC є в CAM → точково на 1 порт.
  • Filtering: Source і Destination на одному порту → кадр відкидається.

📚 Теорія, вижимка та терміни — Лекція 3 (802.1Q VLAN, DHCP, ARP)
802.1Q VLAN (Aruba ProVision):
  • VLAN = окремий широкомовний домен L2 (4094 можливих ID, 4-байтний тег 0x8100).
  • untagged — порти до кінцевих пристроїв (ПК/принтер); тег знімається на виході.
  • tagged — магістральні порти між комутаторами/маршрутизаторами.
DHCP (UDP 67/68) & ARP:
  • DORA: Discover → Offer → Request → Acknowledge.
  • ip helper-address — пересилає DHCP-запит через межу VLAN/L3.
  • ARP: Broadcast-запит «Хто має IP X?» → Unicast-відповідь із MAC.

📚 Теорія, вижимка та терміни — Лекція 4 (STP/RSTP/MSTP & LACP)
Spanning Tree (802.1D / 802.1w / 802.1s):
  • Мета: розірвати L2-петлі (Broadcast Storm) без втрати фізичного резервування.
  • Root Bridge: найменший Bridge ID (Priority 0..61440, крок 4096 + MAC).
  • Ролі портів: RP (найкращий шлях до Root), DP (пересилає в сегмент), AP (Blocked/Discarding).
LACP (802.3ad / 802.1AX):
  • Об'єднує 2–8 фізичних портів в один логічний канал (trk1) — сумує швидкість + відмовостійкість.
  • Вимоги до портів: однакові швидкість, дуплекс та налаштування VLAN.
  • admin-edge-port (PortFast) — миттєвий перехід клієнтського порту у Forwarding.

📚 Теорія, вижимка та терміни — Лекція 6 (CIDR, VLSM, Wildcard Mask)
Формули підмереж IPv4:
  • Кількість хостів = 2^(32 - prefix) - 2 (віднімаємо Network ID та Broadcast).
  • Винятки: /31 (RFC 3021, 2 хости для P2P), /32 (маршрут до 1 хоста / Loopback).
  • Шпаргалка масок: /24=254, /25=126, /26=62, /27=30, /28=14, /29=6, /30=2.
Алгоритм VLSM:
  • Завжди сортуй відділи від найбільшого до найменшого!
  • Обирай найменший степінь двійки 2^h - 2 ≥ N_hosts.
  • Wildcard Mask = 255.255.255.255 - SubnetMask (використовується в OSPF та ACL).

📚 Теорія, вижимка та терміни — Лекції 5–6 (LPM, Administrative Distance, Inter-VLAN SVI)
Правила вибору маршруту:
  • 1. Longest Prefix Match (LPM): завжди перемагає найспецифічніша (найдовша) маска (/25 > /24 > /16 > /0).
  • 2. Administrative Distance (AD): порівнюється лише при однакових префіксах (менше = краще).
  • 3. Metric: порівнюється всередині одного протоколу (Cost для OSPF, Hops для RIP).
Стандартні значення AD:
  • Directly Connected = 0 · Static Route = 1
  • eBGP = 20 · OSPF = 110 · RIP = 120
  • Inter-VLAN Routing: потребує ip routing + SVI (vlan X → ip address).

📚 Теорія, вижимка та терміни — Лекція 5 (VRRP · RFC 5798)
Механіка VRRP (FHRP):
  • Декілька маршрутизаторів ділять спільний Virtual IP (VIP) та Virtual MAC 00-00-5E-00-01-XX (XX = VRID hex).
  • IP Protocol 112, Multicast 224.0.0.18.
  • Тільки Master шле Advertisement щосекунди і відповідає на ARP для VIP.
Вибори Master та таймери:
  • Owner (чиїм реальним IP є VIP) має Priority = 255; інші за замовчуванням — 100 (1..254).
  • При рівному Priority перемагає вища первинна IP-адреса!
  • Skew Time = (256 - Priority) / 256 сек; Preempt за замовч. ON.

📚 Теорія, вижимка та терміни — Лекція 7 (OSPFv2 Single Area)
Основи OSPFv2 (Link-State, AD = 110):
  • Area 0 (Backbone): усі маршрутизатори мають ідентичну базу LSDB (LSA Type 1 Router + Type 2 Network) і будують дерево за алгоритмом Дейкстри (SPF).
  • Multicast: 224.0.0.5 (AllSPFRouters), 224.0.0.6 (AllDRouters).
  • Router ID: ручний > найбільший Loopback > найбільший активний IP (має бути унікальним!).
Умови сусідства та DR/BDR:
  • Мають збігатися: Area ID, Subnet Mask, Hello/Dead (10/40s), Auth, Stub-прапори (MTU ламає на ExStart!).
  • DR/BDR: найвищий Priority (0 = не бере участі), потім найвищий RID. Без Preempt!
  • Cost = Reference BW / Interface BW (мін. 1).

📚 Теорія, вижимка та терміни — Лекція 8 (Stacking: Backplane vs VSF, MAD)
VSF (Virtual Switching Framework):
  • Об'єднує комутатори (Aruba 2930F / 6200 / 6300) через стандартні порти 10G/25G SFP+ (до 40 км по оптиці!) в один логічний комутатор.
  • Ролі: Commander (control plane), Standby (гарячий резерв), Member.
  • Топологія Ring (кільце) витримує розрив 1 кабелю без Split-Brain!
VSF vs Backplane Stacking & MAD:
  • Backplane Stacking (2930M / 3810M): спеціальні короткі модулі/кабелі (до 1–3 м) у межах однієї стійки.
  • Split-Brain: розпад стеку (в Chain або при 2 обривах у Ring) на два активних стеки з 1 IP/MAC.
  • MAD (LLDP / VLAN): виявляє Split-Brain і вимикає порти меншого фрагмента.
